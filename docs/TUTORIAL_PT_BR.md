# CataMedia — início rápido em português

Este guia se aplica ao **CataMedia C# 3.x para Windows x64**.
Para a versão PowerShell 2.x, consulte a [documentação histórica](https://github.com/Wisleyv/media_download/tree/v2.0.1/docs).

1. Escolha instalador ou ZIP portátil de uma release C# 3.x na [página oficial](https://github.com/Wisleyv/media_download/releases). Confira origem e checksums.
2. Instale por usuário e abra pelo menu Iniciar, ou extraia todo o ZIP em uma pasta gravável e abra `CataMedia.exe`. Não é necessário instalar o .NET separadamente.
3. Abra **Componentes**, selecione yt-dlp e confirme **Obter / atualizar** após a consulta. Repita para FFmpeg + FFprobe e Node.js, sem sair da janela.
4. Cole os links, um por linha. Escolha destino, vídeo MP4 ou áudio MP3/WAV/FLAC e as opções pertinentes.
5. Clique em **Baixar**, responda à confirmação de playlist se aparecer e acompanhe a fila. Selecione o resultado concluído e use **Abrir pasta**.
6. Use **Salvar preferências** para guardar idioma e escolhas. Para uma falha, consulte os detalhes do item e corrija a causa antes de repetir.
