# Identidade CataMedia

`CataMedia.png`: arte gerada com a ferramenta integrada imagegen, baseada na referência
local fornecida pelo usuário `tests/base_para_icone.jpg`. A referência permanece local.
Uso: cabeçalho e Ajuda/Sobre. Fundo transparente, cata-vento com quatro cores e seta de download.

`CataMedia.ico`: conversão da arte PNG, sem mudar o desenho, para quadros de 16, 20, 24,
32, 40, 48, 64, 128 e 256 pixels, com alpha. Redução bicúbica de alta qualidade via
System.Drawing; quadros PNG encapsulados em ICO. Uso: executável, janela, atalhos e Setup.

Prompt final enviado à ferramenta integrada:

> Use case: logo-brand. Asset: Windows desktop application icon for CataMedia. Input is reference image for identity. Create one square centered simplified app icon inspired closely by this four-blade pinwheel: magenta pink upper-left, orange upper-right, yellow lower-right, turquoise lower-left. Preserve the pinwheel concept and a simple dark teal download arrow at the center. Remove all text, lettering, tiny symbols (microphone, headphones, music, play), background tile, trails, and fine details. Bold clean silhouette, gently folded blades, restrained shading, recognizable at 16px, saturated balanced colors, no thin stem. Fill about 85 percent of square with generous clear margin. Actual transparent background. Single icon only, no mockup or multiple variants.
